# Learning-LeetCode

Plataforma interativa para estudo e visualização passo a passo de algoritmos do LeetCode em JavaScript.

## Funcionalidades
- Execução e rastreamento em tempo real de algoritmos
- Visualização de variáveis de escopo, arrays e ponteiros
- Inspeção de coleções hash (`Map` e `Set`)
- Destaque automático e animado de soluções e valores encontrados
- Controles de reprodução passo a passo (Play, Pause, Slider, Avançar, Voltar)
- Suíte de casos de teste automatizada com feedback imediato

## Como rodar localmente

```bash
# Instalar dependências
yarn install

# Iniciar servidor de desenvolvimento
yarn dev
```
